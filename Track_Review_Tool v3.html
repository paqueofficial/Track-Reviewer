Track Review Tool

A simple way to decide which tracks make the cut for your next project.

How it works

  1. Give your project a title, then enter each track's details — name, BPM, key, producers and any feature.
  2. Work down three questions for that track: does it pass the vibe check, are the lyrics strong enough, and is the beat the right one? The tool weighs your answers and gives each track a verdict.
  3. Save the track to your list and move on to the next one, until you've worked through everything and can see clearly what's in and what's out.
  4. When you're ready, export to a Word document for a clean record, save the session as a file you can load back later if you're not finished, or reset the page to start a fresh project down the line.
